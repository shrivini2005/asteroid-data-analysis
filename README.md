# 🚀 NASA NEO Insights Tracking Solution

This project analyzes NASA Near-Earth Object (NEO) data using Python, MySQL, and Streamlit.

## 🔧 Features
- Data collection from NASA API
- Data cleaning and preprocessing
- MySQL database integration
- SQL queries for asteroid analysis
- Interactive Streamlit dashboard
- Search, filter, and visualization options

## 📊 Output
- 10,000+ asteroid records analyzed
- Fastest, closest, and hazardous asteroid insights
- Interactive charts and tables

## 🛠 Tools Used
- Python
- MySQL
- Streamlit
- Pandas
